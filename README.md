# 命途角色 (Paths-Role)

> 星穹列车 (StarRailExpress) 的角色附属包，新增命途角色与玩法。

## 角色

| 角色 | 阵营 | 描述 |
|------|------|------|
| **均衡的巫女** | 特殊中立 | 以香火钱（金币）为核心资源，布置赛钱箱、展开结界、发射阴阳玉 |
| **磕学家** | 特殊中立（欢愉） | 使用磕学之书配对玩家成为恋人，杀手全灭后进入磕学时刻 |
| **赏金猎人** | 杀手方中立（巡猎） | 购买通缉令悬赏目标，击杀目标完成狩猎 |

## 系统

- **神社系统** — 巫女召唤神社，全体传送进入，神社商店内购买物品
- **迷迷系统** — 管理员面板，玩家反馈、数据管理、配置调整
- **休闲游戏** — 内置斗公司等小游戏
- **邮箱系统** — 玩家间发送邮件
- **命途故事集** — 查看各角色背景故事

## 特殊物品

| 物品 | 效果 |
|------|------|
| 如我所书 | 多合一功能菜单（故事集、游戏、迷迷、反馈、播放控制、邮箱） |
| 窥探之眼 | 透视带盾玩家，右键直接破盾 |
| 小花玩偶 | 小花的玩偶，投掷后触发爆炸菜单 |

## 依赖

- **Minecraft** `1.21.1`
- **Java** `>=21`
- **Fabric Loader** `>=0.18.2`
- **Fabric API** `*`
- **StarRailExpress** `>=4.3.0`
- **Cardinal Components API** `>=6.1.1`
- **Simple Voice Chat** (可选)

## 安装

1. 安装 Fabric Loader 和 Fabric API
2. 安装 StarRailExpress v4.3.0+
3. 安装 Cardinal Components API v6.1.1+
4. 将 `.jar` 放入 `mods` 文件夹
