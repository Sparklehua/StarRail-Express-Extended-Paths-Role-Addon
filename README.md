# 命途角色 (Paths-Role)

> 星穹列车 (StarRailExpress) 的角色附属包，新增命途角色与玩法。

## 角色

### 均衡的巫女

| 项目 | 内容                                                                                                                              |
|------|-----------------------------------------------------------------------------------------------------------------------------------|
| **阵营** | 特殊中立                                                                                                                          |
| **简介** | 均衡神社的巫女，以香火钱（金币）为核心资源。无心情系统，不会疯狂。疾跑时间为常人的2.5倍。没有杀手直觉，在杀手直觉中显示为品红色。 |
| **巫女符纸** | 开局获得巫女符纸，提供一层护盾。护盾被击破时消耗背包的符纸，并且购买冷却10s。破盾者会被阴阳玉自动追踪。                           |
| **核心玩法** | 放置赛钱箱被动获取香火钱，满足金额条件且平民=杀手时获胜。可展开结界保护自己，手持御币发射阴阳玉反击破盾者。                       |
| **免疫特性** | 对部分角色技能免疫，不阻碍其他中立胜利条件。无法成为恋人。                                                                        |

### 磕学家

| 项目 | 内容 |
|------|------|
| **阵营** | 特殊中立（欢愉） |
| **简介** | 以磕CP为乐的特殊中立角色。无限体力、本能透视、免疫黑暗与失明。默认可被杀手直觉看到。 |
| **观察模式** | 默认开启，静止3秒渐隐→4秒完全隐身。完全隐身时不被杀手直觉看到。移动到一定距离后恢复可见。技能键切换开关（5秒冷却）。 |
| **核心玩法** | 使用磕学之书右键配对两名玩家成为恋人，让他们存活到最后即可获胜。恋人被杀则进入暴怒追踪凶手吸入书中抹杀。杀手全灭后触发磕学时刻，需清除非恋人。 |

### 赏金猎人

| 项目 | 内容 |
|------|------|
| **阵营** | 杀手方中立（巡猎） |
| **简介** | 慧星酒吧名气第一的猎人，只接最不要命的买卖。银河之大，最不缺的就是亡命的恶徒——他们是能动的钱袋子。 |
| **核心玩法** | 购买通缉令交予杀手阵营玩家，由杀手悬赏人选目标后交还，赏金猎人右键接受开始狩猎。击杀目标进入90秒冷却。只能攻击当前通缉目标。可购买临时护盾（120g，悬赏结束后消失）。杀手胜利即可获胜。 |

## 系统

| 系统 | 说明 |
|------|------|
| **神社系统** | 巫女召唤神社，全体传送进入。神社内其他玩家禁用技能/物品/语音，60秒后全体退出。神社商店可购买绝大多数物品。 |
| **迷迷系统** | 管理员面板，支持玩家反馈、数据管理、配置调整、数据统计。 |
| **休闲游戏** | 内置斗公司等小游戏，通过如我所书或菜单进入。 |
| **邮箱系统** | 玩家间发送邮件，支持主题和正文。 |
| **命途故事集** | 查看各角色背景故事与详细玩法说明。 |

## 特殊物品

| 物品 | 说明 | 注意事项 |
|------|------|----------|
| 如我所书 | 多合一功能菜单（故事集、游戏、迷迷、反馈、播放控制、邮箱），右键使用 | 部分功能暂未完全实现 |
| 窥探之眼 | 透视带盾玩家，右键直接破盾 | 需无遮挡物对准目标，否则无法锁定 |
| 小花玩偶 | 小花自制的小玩偶，里面藏着小菜单哦~ | 投掷后落地触发菜单，小心砸到不该砸的人 |

## 依赖

- **Minecraft** `1.21.1`
- **Java** `>=21`
- **Fabric Loader** `>=0.18.2`
- **Fabric API** `*`
- **StarRailExpress** `>=4.3.0`
- **Cardinal Components API** `>=6.1.1`
- **Simple Voice Chat** (可选)

## 安装

1. 安装 Fabric Loader 和 Fabric API
2. 安装 StarRailExpress v4.3.0+
3. 安装 Cardinal Components API v6.1.1+
4. 将 `.jar` 放入 `mods` 文件夹

## 构建

| 项目 | 要求 |
|------|------|
| **JDK** | 21+（Temurin 推荐） |
| **Gradle** | 使用项目自带 `gradlew`，无需额外安装 |
| **内存** | 至少分配 4GB（已在 `gradle.properties` 配置） |

### 前置准备

`libs/` 目录下的依赖 jar 不会被提交到仓库，构建前需手动放入：

```
libs/
├── star_rail_express-4.3.0.jar    ← 主模组，从 StarRailExpress 获取
└── wathe-1.3.2-1.21.1.jar         ← 从 Modrinth 下载
```

### 构建命令

```bash
# 编译
./gradlew build

# 产物路径
# build/libs/Paths-Role-1.0.0.jar
```

### 常见问题

| 问题 | 解决 |
|------|------|
| `未找到 libs/star_rail_express-4.3.0.jar` | 将主模组 jar 放入 `libs/` 目录 |
| `未找到 libs/wathe-1.3.2-1.21.1.jar` | 从 Modrinth 下载 wathe mod 放入 `libs/` |
| `Unsupported class file major version XX` | JDK 版本不对，需要 JDK 21 |
